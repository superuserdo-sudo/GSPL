Philosophy

GSPL follows a neutral approach to software distribution.

It does not require developers to adopt a particular development philosophy, publish their source code, release their modifications, or choose between open-source and closed-source development.

Its purpose is to define the permissions granted by the copyright holder and the conditions that apply when those permissions are exercised.
